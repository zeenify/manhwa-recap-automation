## HOW TO USE THIS FILE (reader agent instructions)

1. **Read this file ONCE before scanning any views.** Memorise the visual markers.
2. When you see a character whose appearance matches a visual marker above,
   use their **canon name** in the `event` field. Example:
   - BAD: `"A dark-haired young man slams his sword into a burst of flame"`
   - GOOD: `"Kang Tae Wook slams his sword into a burst of flame, eyes burning red — fire-class martial arts"`
3. When a technique or world element appears, name it by concept:
   - BAD: `"A blue tornado circle appears"`
   - GOOD: `"Tae Wook's Route activates"` (if that's what it is) or `"unclear: energy effect — might be Route activation or aura manifestation"`
4. **If genuinely uncertain** about identity (new character, or two characters look
   similar from this angle), use a visual description AND flag it:
   `"unclear: blond man in a suit — might be Lee Yun Jae or Ha Tae Yong (both blond)"`
5. **New characters** not in this bible: describe them visually as before. The
   main session will add them to this file after the chapter is done.
6. The `characters` list in your **handoff file** should use canon names for known
   characters and visual descriptions only for genuinely new/unidentified ones.
7. Rule 10 (attribution strictness) still applies — do not INVENT identity.
   Naming a character you recognise is not invention; it is reading comprehension.
   Guessing a name for someone you cannot visually confirm IS invention.
